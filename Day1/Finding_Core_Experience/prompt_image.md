# 핵심 경험 순간 장면 이미지 프롬프트

## 사용 방법

가치 문장 속 "핵심 경험 순간"을 이미지 한 장으로 만들어, 팀이 같은 장면을 떠올리게 하는 프롬프트입니다. 완성된 UI 디자인을 만드는 도구가 아닙니다.

1. 아래 **프롬프트 템플릿**을 GPT 대화창에 붙여 넣습니다.
2. `# 입력` 칸을 우리 앱 내용으로 채웁니다. 채우는 방법은 **입력 예시**를 참고하세요.
3. GPT가 1단계로 장면을 정리하고 확인 질문을 하면, 답하고 확인해 줍니다.
4. 2단계에서 이미지가 만들어지면, 3단계 자기 점검을 읽고 필요한 부분만 수정을 요청합니다.

## 프롬프트 템플릿

아래 블록 전체를 복사해서 쓰고, `# 입력` 칸만 바꿉니다.

```
# 역할
너는 앱 기획 단계에서 "핵심 경험 순간"을 한 장의 장면 이미지로 시각화하는 UX 스토리보드 아티스트야.
목적은 완성된 UI 디자인이 아니라, 사용자가 앱에서 가치를 느끼는 순간을 팀원들이 같은 그림으로 떠올리게 하는 것이야.

# 입력
- 가치 문장: {누구}가 {어떤 상황}에서 {무엇}을 할 수 있게 되어, {어떤 변화/감정}을 얻는다.
- 사용자: (나이대, 특징, 지금 처한 상태)
- 장소와 시간: (예: 비 오는 평일 저녁, 지하철 플랫폼)
- 그 순간의 행동: (사용자가 실제로 하고 있는 동작)
- 앱 이전의 상태: (이 순간 직전에 겪던 불편이나 감정)
- 그 순간의 감정: (안도, 놀람, 뿌듯함 등)
- 화면에 보여야 할 것: (있다면 한 가지만. 없으면 "없음")

# 진행 방식
1단계 — 장면 정리 (이미지를 아직 만들지 마)
입력을 바탕으로 아래 항목을 짧게 정리해서 보여줘.
- 구도: 카메라 위치와 거리 (예: 어깨 너머 시점, 미디엄 숏)
- 인물: 표정, 자세, 시선 방향
- 배경: 상황을 설명해 주는 소품과 환경 2~3개
- 기기: 기기가 장면에서 차지하는 비중과 화면에 보이는 것 (단순한 형태로만)
- 감정 연출: 빛, 색감, 분위기로 감정을 어떻게 드러낼지
입력이 모호하거나 장면이 기능 설명에 치우쳐 있으면 확인 질문을 최대 3개까지 해줘.
내가 확인하면 2단계로 넘어가.

2단계 — 이미지 생성
아래 규칙을 지켜서 이미지 한 장을 만들어줘.
- 주인공은 사람과 상황이야. 기기 화면은 장면의 일부일 뿐 화면을 가득 채우지 마.
- 화면 UI는 단순한 도형과 색 블록으로만 표현해. 읽을 수 있는 글자, 실제 앱 UI 재현, 실제 브랜드 로고는 넣지 마.
- 이미지 안에 텍스트, 말풍선, 캡션을 넣지 마.
- 스타일: 부드러운 디지털 일러스트, 차분한 색감, 스토리보드 느낌. 사진처럼 사실적으로 그리지 마. (완성 디자인으로 오해받지 않게)
- 비율: 가로 16:9
- 실존 인물을 닮게 그리지 마.

3단계 — 자기 점검
이미지를 만든 뒤 아래 질문에 한 줄씩 답해줘.
- 이 이미지만 보고 "누가, 어디서, 무엇 때문에, 어떤 감정인지" 알 수 있는가?
- 기능보다 감정이 먼저 보이는가?
- 화면에 글자나 상세 UI가 들어가지 않았는가?
부족한 점이 있으면 어떻게 고치면 될지 제안해줘.
```

## 입력 예시: 태권도 기본 동작 학습 앱

Swift Student Challenge 수상작인 태권도 앱으로 채운 `# 입력` 칸입니다. 템플릿의 `# 입력` 부분을 이 블록으로 바꾸면 바로 써 볼 수 있어요.

```
# 입력
- 가치 문장: COVID-19로 집에서 보내는 시간이 긴 사용자가 집 안에서 체력 증진을 하고 싶은 상황에서 태권도 기본 동작을 배울 수 있게 되어, 한국의 전통 무술에 대한 지식을 얻는다.
- 사용자: 20대 후반 직장인. 재택근무가 몇 달째 이어져 하루 대부분을 의자에 앉아 보낸다. 태권도는 배워 본 적이 없다.
- 장소와 시간: 평일 오후 6시, 업무를 막 끝낸 작은 원룸. 창으로 노을빛이 들어오고, 책상에는 노트북이 열려 있고, 현관 옆 고리에 마스크가 걸려 있다.
- 그 순간의 행동: 의자를 밀어 둔 좁은 매트 위에서, 낮은 탁자에 세워 둔 아이패드 속 시범 동작을 보며 앞차기를 처음으로 제대로 끌어올려 차는 중이다.
- 앱 이전의 상태: 몸이 굳고 답답하다. 홈트 영상은 따라 하다 매번 지루해져 사흘을 못 넘기고 그만뒀다.
- 그 순간의 감정: 동작이 맞았다는 뿌듯함과, "이게 태권도 기본이구나" 하는 새로운 호기심.
- 화면에 보여야 할 것: 흰 도복을 입은 단순한 실루엣 캐릭터가 앞차기 시범을 보이는 모습.
```

채울 때 볼 점

- **사용자**는 "집에 오래 있는 사람"에서 멈추지 않고, 그림으로 그릴 수 있게 한 사람으로 좁혔습니다.
- **장소와 시간**에는 상황을 말해 주는 소품(마스크, 열린 노트북)을 넣었습니다. 글자 없이도 "팬데믹 시기 재택"이 읽힙니다.
- **행동**은 "태권도를 배운다"가 아니라 한 순간의 동작(앞차기)으로 썼습니다.
- **화면**에는 한 가지만 남기고 실루엣으로 제한했습니다. 상세 UI가 그려지면 장면의 주인공이 사람에서 화면으로 바뀝니다.

## 사용 팁

- **Before / 순간 / After 3컷 버전**: 2단계를 "같은 인물과 같은 스타일로 세 장을 만들어줘. 1컷은 앱 이전의 불편, 2컷은 핵심 경험 순간, 3컷은 그 이후의 변화"로 바꾸면 Before → After까지 한 번에 보여줄 수 있어요.
- **수정 요청**: "다시 그려줘" 대신 "인물 표정에 뿌듯함이 더 보이게, 기기 비중은 지금의 절반으로"처럼 1단계 항목 이름을 짚어서 요청하면 결과가 덜 흔들려요.
- **글자를 빼는 이유**: 이미지 모델은 화면 속 글자, 특히 한글을 깨뜨리기 쉽습니다. 또 상세 UI가 그려지면 팀이 그 화면을 기정사실처럼 받아들이게 됩니다.
- **장면이 안 그려진다면**: 가치 문장을 다시 보세요. 상황과 결과가 서로 이어지지 않으면 한 장면에 담기 어렵습니다.
